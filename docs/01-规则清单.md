# 01 规则清单（录取规则的唯一依据）

> 用途：投档引擎、自动化测试、验收自查都以这份文档对齐。有歧义先在这里改并记录，再同步通知全组。
> 来源：任务书《简化广州中考公办高中录取模拟系统》第二～五章。本课设是教学模拟，只按本清单实现，不照搬现实政策。

## 0. 术语

| 术语 | 定义 |
| --- | --- |
| L | 全市公办高中最低控制线，输入参数，示例 492。总分低于 L 的考生不参与任何录取 |
| G₁ | 第一梯度线，输入参数，示例 712 |
| Δ | 梯度间隔，输入参数，默认 40 |
| 梯度 | 第 1 梯度：总分 ≥ G₁；第 k 梯度（k≥2）：G₁−(k−1)Δ ≤ 总分 < G₁−(k−2)Δ；最后一档截至 L。**恰好等于某条梯度线，归入较高的那一档** |
| 同分序号 | 同一总分内唯一、数值越小越优先。生成规则为选做（可随机），但同分者序号不得相同 |
| 有效计划数 | 初始名额 ＋ 转入名额 − 转出名额 |
| 最低录取分 | 该计划已录取考生总分的最小值 |
| 末位考生 | 按该计划实际录取顺序最后录取的人（要报总分、志愿序号、同分序号）。**末位考生 ≠ 最低分考生** |
| 无人录取 | 最低分/末位考生均显示"无"，禁止用 0 代替 |

## 1. 批次与志愿

| 批次 | 内容 | 志愿上限 | 主要规则 |
| --- | --- | --- | --- |
| 第一批 | 自主招生 | 1 | 资格名单 + 考核排名 + 计划控制线，不用梯度 |
| 第二批 | 名额分配 | 3 | 高中×初中的名额，初中之间互相隔离 |
| 第三批 | 示范性高中统招 | 6 | 梯度 → 志愿 → 分数 |
| 第四批 | 非示范高中统招 | 6 | 梯度 → 志愿 → 分数 |

- 每所高中只在第三批或第四批之一设置统招接收计划。
- 只有第三批招生高中才有第一批（自主招生）和第二批（名额分配）。
- 招生计划切分（数据准备阶段）：总计划 → 自招 10%（有自招资格才切）→ 名额分配 = 总计划×50% → 剩余为第三批统招。第四批高中无自招无名额分配，只在第四批招生。
- 例：某校总计划 400 → 自招 40 ＋ 名额分配 200 ＋ 第三批统招 160。
- 自招、名额分配可另设计划控制线，**不得低于 L**。

## 2. 投档总流程（伪代码）

```
输入: L, G1, Δ, 数据快照(学校/计划/考生/资格/志愿), 数据版本号
输出: 录取记录, 计划余额, 结转流水, 跳过日志

1) 运行前校验（见 §4），不通过则拒绝运行
2) 生成梯度线表: G1, G1-Δ, G1-2Δ, ... 直到 < L 截止
3) for 批次 in [1, 2, 3, 4]:
       a. 按该批规则投档（§3）
       b. 已录取考生立即退出该批及后续批次
       c. 批次结束后: 未完成名额结转（仅第 1、2 批，见 §5）
4) 运行后校验系统约束（§6），输出结果
```

## 3. 各批次投档规则

### 3.1 第一批 自主招生（不用梯度、不按志愿轮次）

```
候选 = 填报该校(第一批志愿) ∧ 在资格名单内 ∧ 总分 ≥ 该计划控制线
按 考核排名 升序录取，直到计划满额（排名在该校内唯一）
```

### 3.2 第二～四批（梯度 → 志愿 → 分数，三层嵌套）

```
for 梯度 in [第1梯度 .. 最后一档]:
    for 志愿序号 in [1 .. 该批志愿上限]:
        for 计划 in 本批次计划:
            # 第二批的计划单元是"高中×初中"，第三四批的计划单元是"高中"
            候选 = 报该计划且志愿序号=当前 ∧ 总分落在本梯度
                   ∧ 尚未录取 ∧ 总分 ≥ 计划控制线
                   ∧ (第二批额外要求: 考生所属初中 = 该名额单元对应初中)
            候选按 (总分 降序, 同分序号 升序) 排序
            依序录取，直到该计划满额
```

关键点：

- **禁止**"按考生总分排序后逐个扫描其全部志愿"的实现方式（任务书明令禁止）。
- 同一志愿轮次内，不同计划互相独立，各计划只在自己的候选池里录取。
- 第二批名额只允许本初中考生竞争，不同初中的名额不得互相挤占。

### 3.3 官方示例（自查用）

G₁=720、第二梯度线=680、L=600，A 校统招 2 人。甲 690 分第一志愿报 A；乙 710 分第二志愿报 A 且第一志愿校已满。同处第二梯度：第一志愿轮次先录甲，第二志愿轮次录乙。A 校最低录取分 690，末位考生乙（710 分、志愿序号 2）。

## 4. 运行前校验（异常输入应拒绝或提示）

| # | 校验项 | 处理 |
| --- | --- | --- |
| V1 | 重复考生编号 | 拒绝 |
| V2 | 总分非法（非数字/超范围，满分 810 可配置） | 拒绝 |
| V3 | 同分序号：同一总分内重复 | 拒绝 |
| V4 | 同一批次内重复填报同一高中 | 拒绝 |
| V5 | 志愿引用不存在的计划/高中，或批次不匹配 | 拒绝 |
| V6 | 名额分配子计划总额超过该计划初始名额 | 拒绝 |
| V7 | 计划控制线 < L | 拒绝 |
| V8 | 考核排名在同一高中内重复 | 拒绝 |
| V9 | 参数非法：如 Δ≤0、G₁<L | 拒绝 |
| V10 | 高中统招批次不在 {第三批, 第四批}，或一所高中在两个批次都有统招计划 | 拒绝 |

## 5. 结转规则

- 第一、第二批结束后，未完成名额**并入本校第三批统招计划**（本课设只转第三批）。
- **只结转一次**：重复执行运行不能再次增加名额。
- 第二批：先按高中汇总各初中剩余名额，再统一转入。
- 第三、四批余缺**不互转**，最终保留为未完成计划。
- 有效计划数 = 初始 ＋ 转入 − 转出；必须保留结转流水（来源批次/计划/初中、去向、数量、时点）。

## 6. 系统约束（每次运行后必须全部成立）

① 每名考生每次模拟最多录取一次；
② 每条计划录取人数不超过有效名额；
③ 每条录取记录对应有效志愿，且满足资格与分数要求；
④ 初始名额 ＋ 转入 − 转出 = 已录取人数 ＋ 剩余人数；
⑤ 汇总统计与明细一致。

## 7. 统计口径

- 计划数、录取人数、完成率、未录取人数、分数分布；
- 各计划最低录取分 ＋ 末位考生（总分/志愿序号/同分序号），二者分开计算；
- 学校总体统计与分批分类计划统计**分开**；
- 结果支持导出。

## 8. 必测场景（映射自动化测试用例，组员C 按此写断言）

| 用例 | 场景 | 期望 |
| --- | --- | --- |
| T01 | 梯度优先 | 高梯度后志愿优先于低梯度前志愿 |
| T02 | 同梯度志愿优先 | 同梯度内低分第一志愿可优先于高分第二志愿 |
| T03 | 分数与同分顺序 | 同梯度同志愿先比总分，同分再比同分序号 |
| T04 | 边界分数 | 恰好等于控制线/梯度线可进入对应范围；低 1 分进低档或不具资格 |
| T05 | 自主招生 | 未获资格、未达控制线均不能录取；达到条件者按考核排名竞争 |
| T06 | 跨批次排除 | 前批录取者不占后续计划；前批落选者可继续 |
| T07 | 名额分配隔离 | 只能用所属初中的名额，不挤占其他初中名额 |
| T08 | 名额结转 | 余额进入指定统招计划；重复执行不能再次增加名额 |
| T09 | 不足额与空结果 | 无人报考、志愿不足或分数不足时不强行录满 |
| T10 | 统计口径差异 | 最后录取者分数可能高于最低录取分，二者不得混算 |
| T11 | 异常输入 | 重复考生、非法分数、重复志愿、无效计划、重复同分序号应提示或拒绝 |
| T12 | 可重复运行 | 同一快照结果一致；重新运行生成独立结果或安全重置，不叠加旧录取 |

## 9. 高分滑档案例（必做功能，演示重点）

手工构造至少 2 个高分滑档实例：

1. "某批次未录取"型：高分考生在该批次落选。
2. "全部批次结束后仍未录取"型：最终落榜。

其中至少 1 个必须体现：**同梯度内，低分考生因志愿靠前被某校录取，而高分考生因该校志愿靠后落选，且未被该批次其他志愿录取**。

要求：给出完整成绩/计划/志愿数据＋人工推演结果；用系统展示录取过程、结果及落选原因；保持成绩、计划和其他考生志愿不变，仅调整该高分考生的志愿，重新完整投档，对比调整前后的录取结果。

## 10. 快照与可重复运行

- 每次运行保存快照：运行编号、规则参数（L/G₁/Δ）、数据版本号。
- 已完成运行的输入**锁定**，不允许静默修改。
- 重新运行：生成独立结果或安全重置，不得叠加旧录取。
- 数据生成器必须保存随机种子/生成配置，保证可复现。

## 11. 现实参考口径（写报告时注意）

- 参考 2026 年数据：L=492、G₁=712、第三梯度线 632，第一梯度线比例为前 10%（选做功能须说明取整与边界同分处理）。
- 课程不采用现实中的户籍、区域、参考科目等级、特殊类别限制。
- 按前 10% 生成 G₁ 为选做；小数据测试可直接人工设置 G₁。
