# 广州中考公办高中录取模拟系统

软件系统开发实践课程设计（3 人组）。按任务书简化规则，模拟广州中考公办高中四个批次的投档录取：自主招生 → 名额分配 → 第三批统招 → 第四批统招。

**核心评价点**：录取规则正确性（35%）＋ 测试与验证（25%）。界面和框架是次要的，规则实现和测试证据是主要工作。

## 技术栈

- 后端：Java 21 + Spring Boot 3 + Maven（投档引擎做成纯 Java 模块，不依赖框架，便于 JUnit 单测）
- 数据库：MySQL 8（utf8mb4）
- 前端：Vue3 + Element Plus（后续搭建）
- 测试：JUnit 5
- 协作：Git + GitHub（远程仓库名建议 `gz-zk-admission-simulator`）


## Git 协作约定

- 分支：`main`（稳定，只合并） / `dev`（集成） / `feature/<模块>-<昵称>`（个人开发）
- 提交信息：`<type>(<scope>): <说明>`，type 用 feat / fix / docs / test / refactor
- 任何功能先开 feature 分支，完成自测后提 PR 到 dev，至少一人 review 后由技术负责人合并
- **改表流程**：先改 `docs/02-数据库设计.md` 和 `sql/schema.sql`，在群里说明，再动代码
- **规则有歧义**：先在 `docs/01-规则清单.md` 里定下来并记录，不得私下按自己理解实现
